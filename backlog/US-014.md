# US-014 — Explain the methodology and official references

## User Story
As a user, I want to understand the calculation rules and limitations so that I can interpret the estimate.

## Context
Rule metadata and result assumptions are available. The original reference snapshot is 2026-09-30, with 2026 social contributions, the French 2026 assessment scale for 2025 income, and Spanish withholding effective 2026-09-10.

Mockup references:
- `docs/mockups/MK-009-methodology-page.png`
Use the methodology mockup as the primary reference for structured explanations, official references and return-to-calculator navigation.
Implementation note: Acceptance Criteria take precedence over the mockup if a conflict exists.

Dependency contract: US-004 provides authoritative ruleset metadata and source URLs; US-009 provides result terminology and navigation back to the calculator. The methodology page must read version data from the bundled rules rather than duplicating version labels that can drift.

Use `MK-009` for page hierarchy, quick navigation, conceptual cards and France/Spain source sections. The official URLs and year/version wording in this story override any illustrative text visible in the mockup.

## Scope
- In scope: Methodology page, concepts, reference links, supported-profile explanations and translations.
- Out of scope: New tax formulas, personalized tax advice and runtime rule updates.

## Acceptance Criteria
- [ ] AC-1: The /methodology page explains supported profiles, income years, rule validity, omitted cases and official references for each country.
- [ ] AC-2: It distinguishes cash net, payroll taxable net, withholding, projected annual tax and monthly averages.
- [ ] AC-3: It links to official sources and calculators; calculation remains independent of visiting those links.
- [ ] AC-4: The page is translated into es/fr/en and returning to the calculator preserves its form.

- [ ] AC-5: The desktop page follows `MK-009` for content hierarchy and quick navigation, with accessible headings and landmark structure.
- [ ] AC-6: Displayed ruleset/version labels are derived from local rule metadata rather than duplicated hard-coded strings where the metadata already exists.

- Implementation plan:
  1. Build a `/methodology` page with semantic sections matching `MK-009`: overview, supported profiles, concepts, France methodology, Spain methodology, omitted cases and official references.
  2. Reuse rule metadata/source lists from the local France/Spain rulesets where available; keep explanatory editorial copy in translation resources.

  4. Display effective/income/publication years and verification date carefully; keep the French 2026-scale/2025-income projection warning explicit.
  5. Render external official links as ordinary user navigation with clear external-link semantics; calculation must not fetch them.
  6. Add in-page anchors/quick navigation following `MK-009` and a clear action back to `/calculator`.
  7. Preserve calculator form state through existing application state/router behaviour when navigating methodology ↔ calculator.
  8. Translate all content into en/fr/es and ensure long French/Spanish labels wrap without overflow.
- Do not add personalized advice or interpret a user's result on this page; explain rules, scope and limitations only.
