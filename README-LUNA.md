# NetSalary backlog — Luna-ready package

This package contains the 16 enriched user stories in `backlog/` and the referenced mockups in `docs/mockups/`.

Each user story preserves the mandatory structure exactly: front matter, User Story, Context, Scope, Acceptance Criteria, Technical Notes, Validation, and Human Decisions. Detailed functional/technical implementation sequencing is embedded inside the existing sections rather than adding new headings.

Implementation precedence: Acceptance Criteria > User Story scope/context > mockup > visual polish.
